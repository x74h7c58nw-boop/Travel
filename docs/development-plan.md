# 개발 순서

1. **정책과 기술 스택 결정**: 요구사항의 미정 항목, 웹·서버 프레임워크, DB와 사진 저장소 선택
2. **그룹과 여행**: 로그인, 그룹 생성, 초대·참여, 여행지와 날짜 설정
3. **결제 내역**: 결제 등록·수정·삭제, 분담 대상과 부담액 관리
4. **정산**: 개인별 잔액 계산, 송금 안내, 정산 확정 및 재정산 정책 구현
5. **사진과 앨범**: 업로드, 사진 조회, 앨범 생성·편집, 여행원 공유
6. **게시**: 앨범 게시와 공개 범위 관리
7. **배포 준비**: 접근 권한 검증, 파일 관리, 운영 환경 설정

## 핵심 검증 항목

- 초대받지 않은 사용자는 비공개 여행 데이터에 접근할 수 없어야 합니다.
- 분담 대상에서 제외된 여행원에게 비용이 청구되지 않아야 합니다.
- 정산 결과는 전체 금액을 보존하며, 송금 적용 후 모든 잔액이 0이어야 합니다.
- 공개 게시에는 선택한 앨범의 공개 허용 데이터만 포함되어야 합니다.
