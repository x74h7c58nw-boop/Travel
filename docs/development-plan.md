# 개발 순서

1. **정책과 기반**: Next.js + TypeScript 및 Supabase Auth/PostgreSQL/Storage/Realtime을 사용하며 별도 API는 두지 않습니다.
2. **인증**: 이메일 가입·로그인, 세션 복구, 로그아웃, 보호 화면을 구현합니다.
3. **그룹과 여행**: 그룹 생성·초대·참여와 여행지·날짜는 별도 그룹/여행 작업에서 구현합니다. 앨범은 해당 작업의 그룹 테이블 계약을 사용합니다.
4. **결제 내역**: 결제 등록·수정·삭제, 분담 대상과 부담액 관리
5. **정산**: 개인별 잔액 계산, 송금 안내, 정산 확정 및 재정산 정책 구현
6. **사진과 앨범**: 비공개 Storage 업로드, 구성원 사진 조회, 앨범 생성·편집·공유, Realtime 반영
7. **게시**: 앨범 게시와 공개 범위 관리 (후속 범위)
8. **배포 준비**: 접근 권한 검증, 파일 관리, 운영 환경 설정

인증·앨범 기능은 `feature/auth-albums`에 구현했습니다. 그룹 스키마 연동 전에는 실제 다중 계정 공유와 다른 그룹 차단 검증이 보류됩니다.

## 핵심 검증 항목

- 초대받지 않은 사용자는 비공개 여행 데이터에 접근할 수 없어야 합니다.
- 분담 대상에서 제외된 여행원에게 비용이 청구되지 않아야 합니다.
- 정산 결과는 전체 금액을 보존하며, 송금 적용 후 모든 잔액이 0이어야 합니다.
- 공개 게시에는 선택한 앨범의 공개 허용 데이터만 포함되어야 합니다.
