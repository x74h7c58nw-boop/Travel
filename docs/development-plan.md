# 개발 순서

현재 스택은 Next.js + TypeScript + Supabase Auth/PostgreSQL/Storage/Realtime이며 별도 API 서버는 없습니다. 그룹·정산 및 인증·앨범 초기 구현과 자동 검증을 추가했습니다. 로컬 설정은 [그룹·정산 실행 안내](groups-settlement-setup.md), 인증·앨범 연동은 [구현 계약](auth-albums-implementation.md)을 참고하세요.

1. **기반과 인증**: 앱 설정, 이메일 가입·로그인, 세션 복구, 로그아웃, 내부 화면 보호
2. **그룹과 여행**: 그룹 생성·초대·참여, 여행지·기간 설정
3. **결제와 정산**: 결제 등록·수정·삭제, 분담 계산, 송금 안내
4. **사진과 앨범**: 그룹 사진 업로드·조회, 앨범 생성·편집·공유, Realtime 반영
5. **게시**: 앨범 게시와 공개 범위 관리 (후속 범위)
6. **배포 준비**: 접근 권한·파일 보관 정책 검증, 운영 환경 설정

두 작업의 마이그레이션은 `supabase/migrations/20261102000100_groups_settlement.sql`을 먼저 적용한 뒤 `infra/supabase/migrations/20261102190000_auth_albums.sql`을 적용합니다.

## 핵심 검증 항목

- 초대받지 않은 사용자는 비공개 여행 데이터에 접근할 수 없어야 합니다.
- 분담 대상에서 제외된 여행원에게 비용이 청구되지 않아야 합니다.
- 정산 결과는 전체 금액을 보존하며, 송금 적용 후 모든 잔액이 0이어야 합니다.
- 공개 게시에는 선택한 앨범의 공개 허용 데이터만 포함되어야 합니다.
