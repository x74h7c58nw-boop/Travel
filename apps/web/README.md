# 웹 애플리케이션

Next.js App Router 웹 애플리케이션입니다. 루트에서 `npm ci`, `npm run dev`로 실행합니다.

`src/app`은 라우팅·전역 스타일, `src/features/groups`는 그룹·결제 화면과 데이터 접근, `src/features/settlements`는 정산 계산, `src/shared`는 인증 어댑터·Supabase 클라이언트·타입입니다.

로그인 UI와 앨범은 팀원 담당입니다. [협업 계약](../../docs/groups-settlement-design.md)과 [실행·검증 안내](../../docs/groups-settlement-setup.md)를 참고하세요.
